Case study — lexiclock

Shipping a real Android app with no laptop

ProblemAndroid resource compilation needs glibc tools (aapt2) that crash on Android's bionic libc — the phone cannot build an APK.
DecisionStop treating the phone as the build machine. Push code, let GitHub Actions compile, sign and release, then pull the APK back. Keep all time logic in a pure-Kotlin engine with zero Android imports.
Result71 JVM unit tests (including all 1,440 minutes of a day, DST and leap-day edges) run in CI with no emulator, and a signed v1.0.0 APK is built and released straight from the phone.

How I work

  • Constraints first: small RAM, throttling CPU and an OS that kills processes.
  • Scripted, reproducible builds — no "it works on my machine".
  • Ship from the device: write, push, build in CI, pull the artifact back.
  • Measure before optimising: token budgets, binary size, thermal headroom.
